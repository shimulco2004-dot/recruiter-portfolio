06 / Logo story & systemHandy Work · Jeddah

A structural presence.
An existing signature.

The supplied symbol can be read as upright structural elements and a central angular form. This is a contemporary visual reading, not a claim about the original designer’s construction process.

The original English wordmark and general-contracting descriptor remain intact. The separable symbol is used only where space is limited; the complete logo leads formal communications.

07 / Clear space & minimum sizeHandy Work · Jeddah

Give the mark
room to work.

Define x as the width of one outer upright in the supplied symbol. Keep at least x clear space around the complete logo. This is a practical usage rule developed for this system.

Recommended starting minimum: complete logo 45 mm in print or 220 px digitally. Symbol alone: 8 mm or 32 px. Check the actual substrate and viewing distance before production.

Proportion: original master canvas 1672:941. Scale uniformly. Never rebuild the mark with live type.

Navy anchors the system. White and off-white give information room. Orange signals a direction or an important moment; sand brings warmth to the architectural context.

Target balance: navy 45%, whites 30%, orange 15%, sand 5%, charcoal 5%. RGB values are the web master; printed color requires substrate proofing.

09 / TypographyHandy Work · Jeddah

Clear by design.

DIN Next is the preferred English family; DIN Next Arabic is its Arabic partner. This delivered web system uses the specified IBM Plex Sans and IBM Plex Sans Arabic fallbacks, with locally hosted fonts.

Bold for statements. Medium for hierarchy. Regular for clear reading. The logo wordmark is supplied vector artwork, never substituted typography.
